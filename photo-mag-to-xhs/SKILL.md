# Photo Magazine to Xiaohongshu Pipeline (摄影杂志精读转小红书全能流水线)

本技能是一套端到端的全自动化流水线（Pipeline），专用于将国内外顶级摄影杂志（如《Aperture》、《National Geographic》、《British Journal of Photography》、《中国摄影》、《摄影之友》、玛格南摄影画册、大师专访特刊等 PDF 或文本），一站式转化为符合小红书爆款规范的画廊级图文交付包。

---

## 依赖环境与预检 (Prerequisites)

本流水线附带的自动化脚本位于当前技能目录下的 `scripts/` 文件夹中：
- Python 3.8+
- `Pillow`：卡片渲染工具（若未安装可运行 `pip install Pillow`）
- `pdftotext` (Poppler) 或 `pypdf`：PDF 文本解析（`brew install poppler` 或 `pip install pypdf`）

---

## 流水线架构与执行阶段

```
[ 摄影杂志 / 摄影专刊 PDF / 文本 ]
       │
       ▼ (阶段 1: 美学与技法萃取)
 提炼：视线引导、光影雕刻、焦段视角、色彩影调、决定性瞬间、大师金句
       │
       ▼ (阶段 2: 爆款文案网感重构)
 生成：3~5组不同风格标题 + 黄金4段式正文 + 实拍参数清单 + 摄影话题标签
       │
       ▼ (阶段 3: 画廊级视觉渲染 1080x1440)
 自动调用 Python 渲染 3:4 哑光暗房风卡片 (封面卡 + 拍摄配方清单卡 + 避坑对比卡)
       │
       ▼ (阶段 4: 打包交付)
 组装 xhs_bundle 交付包，输出包含有序图片序列与发布文本的最终交付物
```

## 详细执行指南

当用户提供摄影杂志文件（如 `/path/to/magazine.pdf`）、文字长文或要求解读某期摄影主题时，按以下四个阶段推进：

### 阶段 1：解析杂志提炼美学干货 (Magazine Extraction)

1. 若用户提供了 PDF 文件，运行提取脚本：
   ```bash
   python3 scripts/extract_magazine.py "<pdf_path>" --json
   ```
   *(注：在执行时，请将 `scripts/extract_magazine.py` 替换为当前 skill 目录下的对应实际路径)*

2. 从杂志或长文中深度提炼出 5 个核心要素：
   - **痛点对号入座**：摄影爱好者在日常扫街、人像或风光中常犯的哪种“废片/游客照”习惯与本期内容直接对应？
   - **视线动线与构图**：并非死记硬背九宫格，而是大师如何运用**引导线、负空间留白、多图层景深（前景-中景-背景）、框架式构图**构建空间叙事。
   - **光影与影调哲学**：自然光方向（顺光/侧逆光/局部点光/黄金时刻）、反差控制、明暗交界线的利用。
   - **器材与参数密码**：推荐焦段选择（如 28mm/35mm/50mm/85mm）、光圈景深思考（大光圈虚化 vs 小光圈交代环境）、快门速度与动态抓拍时机。
   - **大师原话与思维提升**：提炼 1~2 句穿透力极强的大师金句或编辑卷首语。

---

### 阶段 2：创作小红书爆款文案 (Viral Copywriting)

遵循小红书高赞摄影笔记的心理学模型，产出具备收藏价值的结构化文案：

#### 1. 标题四重奏（输出 3~5 个不同风格候选标题供用户选择）
- **反常识悬念型**：颠覆新手认知，击中痛点（例：《拍了3年才明白：照片没有高级感，根本不是镜头的问题！📷》）
- **顶级名刊背书型**：借助权威背书拉升信任度（例：《翻完《国家地理》最新特刊：顶流摄影师偷着用的3个构图法门⚠️》）
- **参数公式导向型**：实操直接抄作业（例：《偷师顶级摄影杂志：阴天逆光人像的“保姆级参数公式”（建议收藏）📊》）
- **审美阶层跃迁型**：击中摄影品味与进阶欲（例：《为什么你的照片总像游客照？顶级大师教你用“视线动线”讲故事🎨》）

#### 2. 正文“黄金 4 段式”结构模板

```markdown
[痛点开场 Hook]
👉 你是不是也经常有这种困惑：[描述摄影人最扎心的痛点，例如：同样是扫街/拍人像，为什么别人拍出来是电影感大片，自己拍的就像随手拍的游客照]？
很多人第一反应是怪设备不够好、没有大光圈镜头，其实根本不是！

[名刊硬核破局]
📖 最近深读了 [杂志名称，如《Aperture》/《中国摄影》] 的最新专题：
特邀摄影师团队拆解了 [大师姓名/代表作组照] 的幕后拍摄逻辑，
发现了一个醍醐灌顶的视觉底层法则：
👉 [用一句话白话概括核心认知，如：决定画面高级感的不是光圈大小，而是画面明暗层级的层次与负空间呼吸感]

[底层视觉逻辑拆解]
💡 为什么这个方法能让废片秒变大片？通俗点拆解：
1. 【视线牵引】：[解释视觉重心与引导线条，如何不让观众眼花]
2. 【光影雕刻】：[解释侧逆光与阴影如何塑造被摄物体的立体骨架]
3. 【画框减法】：[解释如何剔除杂乱背景，利用门窗/阴影借景]

[实拍抄作业参数清单 Checklist]
📷 下次出门拍照，直接套用这套大师级实操配方：
1️⃣ 【机位与构图】：[具体机位高低、视平线与留白比例]
2️⃣ 【焦段与景深】：[推荐焦段，如 35mm 交代环境关系，光圈收至 f/4~f/8 保持层次]
3️⃣ 【光线捕捉】：[最佳拍摄时机与测光点选择]
4️⃣ 【快门时机】：[抓拍动态、眼神光或决定性瞬间的手法]

[大师金句与互动结尾]
✨ 正如大师所说：“[插入提炼出的大师金句]。”
💬 评论区交流：你平时最爱挂机的焦段是哪个？下期想看哪位大师或哪本杂志的拆解？
收藏起来，下次出门扫街/拍照前翻一翻！👇
```

#### 3. 广告法与敏感词自检
- 严禁绝对化宣传（禁止使用“最权威”、“100%出片”、“完全碾压”、“国家级大片”等）。
- 尊重版权与引注（注明杂志出处与摄影师姓名）。

#### 4. 话题标签推荐
包含：流量大词（`#摄影 #摄影技巧 #拍照姿势`）、垂直进阶词（`#构图技巧 #光影美学 #相机参数 #扫街摄影 #大师构图`）、美学圈层词（`#审美提升 #胶片摄影 #摄影杂志`）。

---

### 阶段 3：自动渲染 3:4 视觉卡片 (Card Rendering)

调用内置画廊级渲染引擎，自动生成 1080×1440 极简暗房深色风视觉卡片：

1. **渲染封面卡 (Cover Card)**：
   ```bash
   python3 scripts/render_card.py \
     --type cover \
     --title "<选定的大标题>" \
     --subtitle "<一句话核心大师洞察或痛点破局>" \
     --tag "<胶囊标签，如：摄影美学进阶 / 构图底层逻辑>" \
     --output "<output_dir>/slide_01_cover.png"
   ```

2. **渲染实操配方清单卡 (Checklist Card)**：
   ```bash
   python3 scripts/render_card.py \
     --type checklist \
     --title "<清单大标题，如：顶级摄影师私藏的 4 步出片公式>" \
     --points "<步骤1标题>|<步骤1详细描述>" "<步骤2标题>|<步骤2描述>" "<步骤3标题>|<步骤3描述>" "<步骤4标题>|<步骤4描述>" \
     --output "<output_dir>/slide_02_checklist.png"
   ```

3. **渲染避坑对比卡 (Comparison Card，可选)**：
   ```bash
   python3 scripts/render_card.py \
     --type comparison \
     --title "<对比标题，如：新手 vs 摄影大师的核心认知差距>" \
     --amateur-title "<新手盲区标题>" \
     --amateur-desc "<新手错误做法与痛点描述>" \
     --master-title "<大师解法标题>" \
     --master-desc "<杂志大师的正向思维与实操解法>" \
     --output "<output_dir>/slide_03_comparison.png"
   ```

---

### 阶段 4：审核与打包交付 (Package Bundle)

1. 将生成的最终文案保存为 Markdown 文件（例如 `<output_dir>/copywriting.md`）。
2. 运行打包发布脚本，自动检查敏感词并组装交付目录：
   ```bash
   python3 scripts/package_bundle.py \
     --dir "<output_dir>/xhs_bundle" \
     --title "<选定标题>" \
     --content-file "<output_dir>/copywriting.md" \
     --images "<output_dir>/slide_01_cover.png" "<output_dir>/slide_02_checklist.png" "<output_dir>/slide_03_comparison.png" \
     --tags "摄影" "摄影技巧" "构图技巧" "摄影杂志" "审美提升"
   ```
3. 在对话中向用户交付：
   - 候选标题列表（4种风格）与最终采用标题。
   - 完整爆款文案、正文段落与标签。
   - 生成的 3:4 图片链接与预览展示。
   - `xhs_bundle` 交付包路径，提示用户可一键同步或发布至小红书。
