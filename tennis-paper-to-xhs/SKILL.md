# Tennis Paper to Xiaohongshu Pipeline (网球学术论文转小红书全能流水线)

本技能是一套端到端的全自动化流水线（Pipeline），专用于将运动生物力学、运动损伤预防、体能与发力机理等网球学术论文（PDF 或文本），一站式转化为符合小红书爆款规范的图文交付包。

---

## 依赖环境与预检 (Prerequisites)

本流水线附带的自动化脚本位于当前技能目录下的 `scripts/` 文件夹中：
- Python 3.8+
- `Pillow`：卡片渲染工具（若未安装可运行 `pip install Pillow`）
- `pdftotext` (Poppler) 或 `pypdf`：PDF 文本解析（`sudo apt-get install poppler-utils` 或 `brew install poppler`，亦可通过 `pip install pypdf` 作为纯 Python 兜底）

---

## 流水线架构与执行阶段

```
[ 网球学术论文 PDF / 文本 ]
       │
       ▼ (阶段 1: 学术萃取)
 提炼：动力链、角速度、肌电图(EMG)、损伤机制、实践建议
       │
       ▼ (阶段 2: 爆款文案网感重构)
 生成：3~5组爆款标题 + 黄金4段式正文 + 避坑Checklist + 话题标签
       │
       ▼ (阶段 3: 视觉渲染 1080x1440)
 自动调用 Python 渲染 3:4 高对比深空运动风卡片 (封面卡 + 实操清单卡)
       │
       ▼ (阶段 4: 打包交付)
 组装 release bundle 目录，输出包含有序图片与发布文本的最终交付包
```

---

## 详细执行指南

当用户提供网球论文路径（如 `/path/to/paper.pdf`）或论文主要内容时，按以下四个阶段系统化推进：

### 阶段 1：解析论文提炼干货 (Academic Extraction)

1. 若用户提供了 PDF 文件，运行提取脚本：
   ```bash
   python3 scripts/extract_paper.py "<pdf_path>" --json
   ```
   *(注：在执行时，请将 `scripts/extract_paper.py` 替换为当前 skill 目录下的对应实际路径)*

2. 从论文中严格提炼出 4 个核心要素：
   - **痛点对号入座**：业余爱好者在击球或发球时经常犯的哪项错误与该论文机理直接相关？
   - **核心硬核数据**：角度、关节角速度、转动惯量、击球速度增幅、肌电振幅（EMG）比率等关键实测数据。
   - **动力链白话解析**：运用球友易懂的物理力学比喻（如“甩鞭效应”、“弹簧被动蓄力”、“骨盆预刹车”）。
   - **球场实操处方**：提炼 3 个球场上即刻可练习检验的动作纠错点（Checklist）。

---

### 阶段 2：创作小红书爆款文案 (Viral Copywriting)

遵循小红书高赞笔记的心理学模型，产出结构化文案：

#### 1. 标题四重奏（必须输出 3~5 个不同风格的候选标题供用户选择）
- **反常识悬念型**：颠覆认知，击穿痛点（例：《打了5年网球才明白：发球借不上力，原来不是手臂问题！🎾》）
- **顶刊实验背书型**：权威数据拉升信任度（例：《顶刊生物力学实测：90%业余球友网球肘，死在这一个手腕动作⚠️》）
- **数字效果导向型**：明确量化收益（例：《改掉这个发力细节，底线球速暴涨15km/h（附实验数据）📈》）
- **对号入座痛点型**：精准锁定受众（例：《为什么你的正手上旋总打不深？职业选手动力链拆解🔬》）

#### 2. 正文“黄金 4 段式”结构模板

```markdown
[痛点开场 Hook]
👉 你是不是也遇到过这种情况：[描述球友最抓狂的打球痛点/失误现象]？
很多人以为是 [常见错误归因]，其实大错特错！

[顶刊硬核破局]
🔬 最近研读了一篇来自 [期刊/机构/年份] 的重磅研究：
研究团队对 [实验对象，如 20位职业 vs 30位业余选手] 进行了高速红外动捕与肌电测试。
发现了一个颠覆性的结论：
👉 [用一句话白话概括核心机制，并标出 1~2 个关键数据，如：躯干旋转贡献了 54% 动力]

[通俗比喻剖析]
💡 为什么会这样？通俗点说：
[把抽象生物力学拆解为生动比喻：甩鞭子、弹簧蓄力、齿轮咬合、刹车传导等]

[球场实操行动项 Checklist]
🎾 下次去球场练球，死磕这 3 个动作检查点：
1️⃣ 【准备/蓄力】：[具体身体感觉与关节角度]
2️⃣ 【引拍/蹬地】：[力的传导顺序与发力时机]
3️⃣ 【击球/随挥】：[避免代偿损伤的关键制动点]

[互动与收藏结尾]
💬 评论区聊聊：你平时打球也有这个习惯吗？现在的穿线磅数是多少？
收藏起来，下次上场前看一遍！👇
```

#### 3. 广告法与合规自检
- 杜绝绝对化词汇（禁止使用“最权威”、“100%根治”、“包教包会”、“天下第一”等）。
- 运动伤病提示（如涉及网球肘、膝盖疼痛，注明“本文基于运动生物力学文献，具体伤痛请咨询专业医师”）。

#### 4. 话题标签推荐
包含：基础流量词（`#网球 #网球教学 #网球进阶`）、垂直痛点词（`#网球肘 #正手发力 #动力链 #运动生物力学`）、生活圈层词（`#打网球的日常 #网球装备`）。

---

### 阶段 3：自动渲染 3:4 视觉卡片 (Card Rendering)

调用内置渲染引擎生成 1080×1440 高对比深色运动风视觉卡片：

1. **渲染封面卡 (Cover Card)**：
   ```bash
   python3 scripts/render_card.py \
     --type cover \
     --title "<选定的大标题>" \
     --subtitle "<一句话硬核实验结论或痛点破局>" \
     --tag "<胶囊标签，如：网球进阶 / 避坑指南>" \
     --output "<output_dir>/slide_01_cover.png"
   ```

2. **渲染实操清单卡 (Checklist Card)**：
   ```bash
   python3 scripts/render_card.py \
     --type checklist \
     --title "<清单大标题，如：球场实操 3 步纠错法>" \
     --points "<要点1标题>|<要点1具体描述>" "<要点2标题>|<要点2描述>" "<要点3标题>|<要点3描述>" \
     --output "<output_dir>/slide_02_checklist.png"
   ```

---

### 阶段 4：审核与打包交付 (Package Bundle)

1. 将生成的最终文案保存为 Markdown 文件（例如 `<output_dir>/copywriting.md`）。
2. 运行打包发布脚本，自动检查敏感词并组装交付目录：
   ```bash
   python3 scripts/package_bundle.py \
     --dir "<output_dir>/xhs_bundle" \
     --title "<选定标题>" \
     --content-file "<output_dir>/copywriting.md" \
     --images "<output_dir>/slide_01_cover.png" "<output_dir>/slide_02_checklist.png" \
     --tags "网球" "网球进阶" "运动生物力学"
   ```
3. 在对话中向用户交付：
   - 候选标题列表与最终采用标题。
   - 完整文案与标签内容展示。
   - 生成的 3:4 图片预览链接与展示。
   - `xhs_bundle` 交付包路径，提示用户可一键同步或发布。
