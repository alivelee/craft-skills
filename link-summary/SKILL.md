# Link Summary — 链接总结 → 存入笔记

当用户提供一个 URL 并要求"总结"、"摘要"、"存笔记"、"收藏"时，使用本 skill：抓取网页内容 → 生成结构化摘要 → 保存为 Obsidian 笔记。

## 触发场景

- 用户发了一个链接并说"总结这个"、"存到笔记里"、"帮我收藏"
- 用户要求把某篇文章/网页的内容提炼成阅读笔记

## 第一步 — 判断链接类型（分流）

| 链接类型 | 处理方式 |
|---------|---------|
| YouTube / B站视频 | **转交给 `youtube-transcript-summary` skill**，总结完成后再按本 skill 第四步存入笔记 |
| GitHub 仓库主页 | **转交给 `github-repo-analysis` skill**，产出仓库分析后再按本 skill 第四步存入笔记 |
| 普通网页 / 微信 / 知乎 / 博客 | 继续第二步 |

## 第二步 — 抓取内容

按优先级尝试，拿到正文为止：

1. **`web_fetch` 工具**（首选，最快）：直接抓取 URL，返回 markdown。对大多数静态页面有效。
2. **降级 → `browser_tool`**（JS 渲染 / 反爬页面，如微信公众号 `mp.weixin.qq.com`、知乎、X/Twitter）：
   ```
   browser_tool open; browser_tool navigate <url>
   browser_tool snapshot        # 或 evaluate 提取正文
   ```
   微信公众号正文选择器：`#js_content`；标题：`#activity-name`；作者：`#js_name`
   知乎正文选择器：`.RichContent-inner`
   抓取完成后 `browser_tool hide`。
3. **降级 → `curl`**：仅在前两者不可用时使用，并告知用户可能丢失 JS 渲染内容。

**失败处理**：所有方式都失败时，明确报告错误原因（403/超时/需要登录），不要编造内容。

## 第三步 — 生成摘要

摘要语言规则：**中文文章用中文总结；英文文章默认也用简体中文总结**（除非用户要求英文）。

摘要结构（在对话中展示）：

1. **标题 + 来源**（作者/发布平台、发布日期如可得）
2. **一句话摘要**：一段话概括核心内容
3. **关键要点**：3-6 条编号列表
4. **金句/重要引用**（如有）：1-3 条原文摘录
5. **思考与延伸**：这篇文章对读者的价值、可与哪些已有知识关联

## 第四步 — 存入 Obsidian 笔记

### 保存位置

```
04-阅读笔记/网页文章摘要/YYYY-MM-DD-文章标题.md
```

- 日期为**抓取当天**的日期
- 文件名中的标题去除非法字符（`/\:*?"<>|`），过长时截断至 50 字以内
- 同名文件已存在时，在文件名后追加 `-2`、`-3`

### 笔记模板

frontmatter 格式对齐 Vault 的 Clippings 约定：

```markdown
---
title: "文章标题"
source: "https://原始链接"
author: "作者名（未知则省略此行）"
published: YYYY-MM-DD（原文发布日期，未知则省略）
created: YYYY-MM-DD
tags:
  - 阅读笔记
  - 网页摘要
  - <1-2 个主题标签，参考 🏷️ 标签系统总览.md 中的分类，如 人工智能 / 前端开发 / 技术编程>
---

# 文章标题

> [!info] 来源
> [原文链接](https://原始链接) · 作者 · 发布日期

## 一句话摘要

……

## 关键要点

1. ……
2. ……

## 金句摘录

> ……

## 思考与延伸

……

## 相关笔记

- [[相关笔记标题]]（如 Vault 中存在明显相关的笔记则链接，否则省略本节）
```

### 标签规则

- 固定标签：`阅读笔记`、`网页摘要`
- 主题标签：从 `🏷️ 标签系统总览.md` 的现有分类中选 1-2 个最贴切的（如 `#人工智能`、`#前端开发`、`#工具`），**不要发明新的大类标签**

## 第五步 — 反馈

保存完成后，在对话中：

1. 展示摘要正文
2. 给出笔记文件的 `file://` 绝对路径链接（可点击）
3. 一句话说明保存位置和所用标签

## 注意事项

- **不要编造**：抓不到内容就如实说，绝不虚构摘要
- **尊重原文**：摘要基于原文，"思考与延伸"部分可加入分析，但需与原文观点区分
- **批量链接**：用户一次给多个链接时，逐个处理，每个链接生成独立笔记
- **正文长度**：抓取的原文超过 15000 字时，截取主体部分总结，并在笔记中注明"原文较长，摘要基于主要内容"
