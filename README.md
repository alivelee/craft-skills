# Craft Skills

Reusable [Craft Agent](https://thecraftagents.com/) skills.

| Skill | Description |
|-------|-------------|
| [github-repo-analysis](./github-repo-analysis) | Analyze GitHub repositories: structure, languages, activity, and insights. |
| [link-summary](./link-summary) | Fetch and summarize web links into concise notes. |
| [photo-mag-to-xhs](./photo-mag-to-xhs) | Convert photography magazine articles into viral Xiaohongshu posts with 3:4 gallery-style cards. |
| [tennis-paper-to-xhs](./tennis-paper-to-xhs) | Convert academic tennis research papers into viral Xiaohongshu posts with 3:4 cards and structured copy. |
| [youtube-transcript-summary](./youtube-transcript-summary) | Fetch YouTube transcripts and produce bilingual (EN/ZH) summaries. |

## Usage

Copy a skill folder into your Craft Agent workspace `skills/` directory (or your project's `.agents/skills/`), then invoke it by name, e.g. `[skill:youtube-transcript-summary]`.

Each skill folder contains a `SKILL.md` (instructions) and an `icon.svg`.
